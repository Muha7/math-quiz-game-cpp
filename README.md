# Math Quiz Game (C++)

A console-based Math Quiz Game developed using C++. The application generates random arithmetic questions based on the selected difficulty level and mathematical operation. Players answer the questions, receive immediate feedback, and view their final scores.

## Features

- Customizable number of questions (1–100).
- Multiple difficulty levels: Easy, Medium, Hard, and Mixed.
- Four arithmetic operations: Addition, Subtraction, Multiplication, and Division.
- Mixed operation mode with randomly selected operations.
- Random question generation based on difficulty.
- Automatic answer checking.
- Immediate feedback for correct and incorrect answers.
- Final results showing correct and incorrect answers.
- Pass or Fail result evaluation.
- Option to replay the game.

## How to Run

### Prerequisites
- GCC or MinGW C++ compiler.
- Windows operating system for the original console color and screen commands.

### Compilation

```bash
g++ -std=c++11 Math_Quiz_Game_Fixed.cpp -o MathQuiz
```

### Execution

```bash
MathQuiz.exe
```
